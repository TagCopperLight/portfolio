C++ rendering engine built on Vulkan and designed as a universal debugging tool: through a simple network protocol, any program can send it data to visualize in real time, whatever language it is written in. Text stays sharp at any scale thanks to multi-channel signed distance fields (MSDF), instanced rendering draws many elements in few draw calls, and GPU memory is handled by a custom allocator.
